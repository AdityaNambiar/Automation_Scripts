Advantages / Features of Ansible:

1. 'Push' methodology for Configuration Mnaagement.
2. Agentless (Only requirement is.. the target nodes must have python installed)
3. Ansible has an Inventory / Dynamic Inventory
4. It supports Windows & Linux both.
5. It is written in Python.

-> Ansible's control node functionality requires a Linux/Unix environment.
